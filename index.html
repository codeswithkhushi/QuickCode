HTML starter (beginner)

  • <!DOCTYPE html>Tell the browser this is HTML5
  • <html lang="en">Root element of the page
  • <meta charset="UTF-8">Fix weird characters
  • <meta name="viewport" content="width=device-width, initial-scale=1">Needed for mobile layouts
  • <title>My Page</title>Text on the browser tab
  • <link rel="stylesheet" href="style.css">Attach a CSS file
  • <script src="script.js"></script>Attach a JS file (before </body>)
  • <!-- note -->Comment, not shown on page

HTML text and links

  • <h1>Heading</h1>Main heading, h1 to h6
  • <p>Paragraph</p>A paragraph of text
  • <strong>bold</strong> <em>italic</em>Bold and italic text
  • <br>Line break
  • <hr>Horizontal line
  • <a href="https://example.com">Link</a>Link to another site
  • <a href="#about">Go</a>Jump to a section by id
  • <a href="x.html" target="_blank">Open</a>Open link in a new tab
  • <a href="mailto:me@mail.com">Mail</a>Open the email app
  • <div class="box">...</div>Generic block container
  • <span>text</span>Generic inline container

HTML images, lists, tables, media

  • <img src="a.jpg" alt="Describe it">Image with alt text
  • <ul><li>Item</li></ul>Bullet list
  • <ol><li>Item</li></ol>Numbered list
  • <table><tr><th>Name</th><td>Asha</td></tr></table>Basic table: tr row, th head, td cell
  • <video src="a.mp4" controls></video>Video with play controls
  • <audio src="a.mp3" controls></audio>Audio player
  • <iframe src="URL"></iframe>Embed another page
  • <link rel="icon" href="favicon.ico">Tab icon

HTML forms

  • <form action="/send" method="post">Start a form
  • <label for="n">Name</label>Text for an input (match its id)
  • <input type="text" id="n" name="name" placeholder="Your name">Text box
  • <input type="email" required>Email field that must be filled
  • <input type="password">Hidden characters
  • <input type="checkbox"> <input type="radio">Tick box and single choice
  • <textarea rows="4"></textarea>Multi-line text
  • <select><option>One</option></select>Dropdown
  • <button type="submit">Send</button>Submit the form

HTML semantic tags

  • <header> <nav> <main>Top of page, menu, main content
  • <section> <article>Group content, stand-alone post
  • <aside> <footer>Sidebar, bottom of page
  • <div id="x" class="y">id is unique, class can repeat
  • <button disabled>Attribute that turns a button off

CSS selectors and colors

  • p { color: red; }Style every p tag
  • .card { }Style class="card"
  • #hero { }Style id="hero"
  • div p { }p inside a div
  • a:hover { }When mouse is over
  • h1, h2 { }Same style for both
  • * { margin: 0; }Select everything
  • color: #14213d;Text color
  • background-color: rgb(255, 0, 0);Background color
  • :root { --main: #3d7bff; }Define a CSS variable
  • color: var(--main);Use a CSS variable

CSS text and fonts

  • font-family: Arial, sans-serif;Choose font
  • font-size: 1.2rem;Text size
  • font-weight: 700;Bold
  • text-align: center;Align text
  • line-height: 1.6;Space between lines
  • text-decoration: none;Remove underline from links
  • text-transform: uppercase;ALL CAPS
  • letter-spacing: 1px;Space between letters

CSS box model and look

  • margin: 1rem auto;Space outside, auto centers a block
  • padding: 1rem;Space inside the border
  • border: 2px solid #000;Border
  • border-radius: 8px;Rounded corners
  • width: 100%; max-width: 600px;Fluid but capped width
  • height: 100vh;Full screen height
  • box-shadow: 4px 4px 0 #000;Shadow
  • box-sizing: border-box;Padding stays inside width
  • overflow: hidden;Cut off extra content
  • display: none;Hide an element
  • opacity: 0.5;Make see-through
  • cursor: pointer;Hand cursor

CSS Flexbox

  • display: flex;Turn on flex on the parent
  • flex-direction: column;Stack vertically
  • justify-content: space-between;Spread items on the main axis
  • justify-content: center;Center on the main axis
  • align-items: center;Center on the cross axis
  • gap: 1rem;Space between items
  • flex-wrap: wrap;Let items drop to a new line
  • flex: 1;Item grows to fill space
  • align-self: flex-end;Move one item

CSS Grid

  • display: grid;Turn on grid on the parent
  • grid-template-columns: repeat(3, 1fr);Three equal columns
  • grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));Responsive cards, no media query
  • grid-template-rows: auto 1fr;Row sizes
  • gap: 1rem;Space between cells
  • grid-column: span 2;Item takes 2 columns
  • place-items: center;Center every item

CSS position, responsive, motion

  • position: relative;Anchor for absolute children
  • position: absolute; top: 0; right: 0;Place inside a relative parent
  • position: fixed;Stays on screen
  • position: sticky; top: 0;Sticks while scrolling
  • z-index: 10;Layer order
  • @media (max-width: 600px) { }Styles for small screens
  • transition: all .3s;Smooth change
  • transform: scale(1.1) rotate(5deg);Resize or turn
  • @keyframes spin { to { transform: rotate(360deg); } }Define an animation
  • img { max-width: 100%; object-fit: cover; }Responsive image

JavaScript basics

  • console.log("hi");Print to browser console
  • let x = 5; const y = 10;let can change, const cannot
  • function add(a, b) { return a + b; }Define a function
  • const add = (a, b) => a + b;Arrow function
  • if (x > 3) { } else { }Decision
  • for (let i = 0; i < 5; i++) { }Loop 5 times
  • const a = [1, 2, 3]; a.push(4);Array and add item
  • a.map(n => n * 2)New array, each item changed
  • a.filter(n => n > 1)Keep matching items
  • a.lengthNumber of items
  • const p = { name: "Asha", age: 20 };Object
  • `Hello ${name}`Template string
  • setTimeout(() => { }, 1000);Run after 1 second
  • fetch(url).then(r => r.json())Get data from an API
  • JSON.stringify(obj) / JSON.parse(str)Object to text and back

JavaScript DOM and events

  • document.getElementById("q")Find element by id
  • document.querySelector(".card")First match by CSS selector
  • document.querySelectorAll("li")All matches
  • el.addEventListener("click", fn)Run code on click
  • el.textContent = "New";Change text
  • el.innerHTML = "<b>Hi</b>";Change inner HTML
  • el.classList.toggle("on");Add or remove a class
  • el.style.color = "red";Change style from JS
  • document.createElement("li")Make a new element
  • parent.appendChild(el)Add element to page
  • el.setAttribute("href", "#")Set an attribute
  • localStorage.setItem("k", "v");Save in browser
  • localStorage.getItem("k")Read saved value

Git setup and basics

  • git config --global user.name "Name"Set your name once
  • git config --global user.email "me@mail.com"Set your email once
  • git initStart a repo
  • git clone URLDownload a repo
  • git statusSee what changed
  • git add .Stage all changes
  • git add file.txtStage one file
  • git commit -m "message"Save a snapshot
  • git log --onelineShort history
  • git diffSee exact line changes

Git branches

  • git branchList branches
  • git branch featureCreate a branch
  • git switch featureMove to a branch
  • git switch -c featureCreate and move
  • git merge featureMerge into current branch
  • git branch -d featureDelete merged branch
  • git stashHide changes for later
  • git stash popBring stashed changes back

Git undo and fix

  • git restore file.txtThrow away edits in a file
  • git restore --staged file.txtUnstage a file
  • git commit --amend -m "new"Fix last commit message
  • git reset --soft HEAD~1Undo last commit, keep changes
  • git reset --hard HEAD~1Undo last commit and changes
  • git revert HEADSafe undo with a new commit
  • git rm --cached file.txtStop tracking a file

Git and GitHub remote

  • git remote add origin URLConnect to GitHub
  • git remote -vShow remote links
  • git push -u origin mainUpload your commits
  • git pullDownload and merge changes
  • git fetchDownload without merging
  • git tag v1.0Mark a version
  • echo node_modules >> .gitignoreIgnore files in Git

Terminal basics

  • pwdWhere am I? (Windows CMD: cd)
  • lsList files (Windows CMD: dir)
  • cd folderGo into a folder
  • cd ..Go up one folder
  • mkdir myappMake a folder
  • touch index.htmlMake an empty file (PowerShell: ni)
  • cp a.txt b.txtCopy a file (Windows: copy)
  • mv a.txt b.txtMove or rename (Windows: move, ren)
  • rm file.txtDelete a file (Windows: del)
  • rm -r folderDelete a folder
  • cat file.txtShow file content (Windows: type)
  • clearClean the screen (Windows: cls)
  • code .Open folder in VS Code
